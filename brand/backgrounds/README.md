# Wallpapers

Twelve abstract wallpapers for Shotcandy's background picker. Generated for this project with an image model from our own prompts, then upscaled to 2560 × 1440 and encoded as WebP (quality 92). `thumbs/` holds 480 × 270 previews for the picker. Released under the project's MIT license.

| File | Tone | Notes |
|---|---|---|
| strawberry-satin.webp | vivid | silky pink and coral folds |
| peach-dunes.webp | light | golden-hour dunes |
| mint-ripple.webp | light | frosted glass ripples |
| lilac-clouds.webp | light | pastel cloudscape |
| grape-aurora.webp | dark | violet aurora ribbons |
| midnight-bloom.webp | dark | magenta/orange bloom on navy |
| paper-waves.webp | light | layered paper-cut waves |
| candy-chrome.webp | light | iridescent liquid chrome |
| tangerine-grain.webp | vivid | grainy citrus gradient |
| fern-mist.webp | dark | misty green hills |
| gummy-blobs.webp | light | glossy gummy shapes on cream |
| ember-night.webp | dark | charcoal with a warm light leak |

In the app these resolve from `builtin:<name>` asset ids (copy this folder to `public/backgrounds/`).
